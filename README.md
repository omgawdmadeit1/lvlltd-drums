# Step Drum Machine — LVL LTD

16-step drum sequencer with kick, snare, hats, and perc.

## Features
- Play / Stop (Spacebar)
- Tempo 60–180 BPM
- Swing
- Clear / Randomize
- AI genre patterns (House, Hip-Hop, Breaks, Techno, DnB, Afrobeats)
- Visual playhead highlighting
- Track mute (right-click labels)
